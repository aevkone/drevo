# Древо семьи Скиргайло

Генеалогическое древо семьи Скиргайло (Skirgaila / Skirgailo).

Это отдельный проект, не связанный с древом Кочергиных
([aevkone.github.io/roddrevo](https://aevkone.github.io/roddrevo/)).

## Сборка

Править только `data/*.json`, затем `python tools/build.py` — он вставляет данные в `index.html`
и пересчитывает цифры в шапке. Подробности — в начале `tools/build.py`. Секция «Самое первое
упоминание рода» появится сама, когда в репозитории будет скан `img/first/1699.jpg`
(рамку вокруг записи задать в `data/first.json`, поле `box`).
- Адрес после включения Pages: https://aevkone.github.io/drevo/

## Правила работы с данными

- Сведения ищутся только об умерших; о живых — только со слов родственников.
- Разные люди не объединяются в одну карточку.
- В древе не используются пунктирные линии и рамки.
- Ключи и токены в репозиторий не коммитятся.
